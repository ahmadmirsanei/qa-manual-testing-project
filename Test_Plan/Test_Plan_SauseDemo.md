# Test Plan – SauceDemo

1. Introduction
This test plan describes the testing strategy, scope, resources, schedule, and deliverables for manual testing of the SauceDemo web application.

2. Objectives
- Verify core business functionalities such as login, cart, and checkout flows
- Identify functional and validation defects before release
- Ensure application behavior matches expected requirements

3. Scope

In Scope:
- Login functionality
- Product selection
- Add to cart
- Checkout process
- Form validations
- Error message handling

Out of Scope:
- Performance testing
- Security testing
- Mobile application testing

4. Test Approach
- Manual functional testing
- Positive and negative test scenarios
- Exploratory testing
- Smoke testing for critical flows
- Regression testing for existing features

5. Test Environment
- Environment: Demo/Test
- Browser: Google Chrome
- OS: Windows 11
- Test URL: https://www.saucedemo.com

6. Entry Criteria
- Application build is deployed and accessible
- Test environment is stable
- Test data is available

7. Exit Criteria
- All planned test cases executed
- All critical defects reported and reviewed
- Test summary report completed

8. Risks
- Limited test data availability may reduce coverage
- Unexpected application changes without documentation
- Time constraints may limit full regression coverage
