# Test Plan – SauceDemo

## 1. Introduction
This test plan describes the testing approach, scope, resources, and schedule for testing the SauceDemo web application.

## 2. Objectives
- Verify that core functionalities work as expected
- Identify defects before production usage
- Ensure a good user experience

## 3. Scope

### In Scope
- Login functionality
- Product selection
- Add to cart
- Checkout process

### Out of Scope
- Performance testing
- Security testing
- Mobile application testing

## 4. Test Approach
- Manual functional testing
- Test scenarios and test cases derived from requirements
- Positive and negative test cases
- Exploratory testing

## 5. Test Environment
- Browser: Google Chrome
- OS: Windows 11
- Test URL: https://www.saucedemo.com

## 6. Entry Criteria
- Application is accessible
- Test environment is stable

## 7. Exit Criteria
- All planned test cases executed
- Critical defects are reported
- Test summary completed

## 8. Risks
- Limited test data
- Changes in application behavior without notice
